# dotnet-nuget-content 2.0.0 release notes

## Release scope

Version 2.0.0 is the tool version. It applies to the `dotnet-nuget-content` top-level NuGet tool and matching `dotnet-nuget-content.win-x64` Native AOT package. The supported installation and runtime target is Windows x64. It does not change user-created content package versions or the v1 content manifest, project-workspace marker, or existing JSON contracts.

## Included capabilities

- Immutable content snapshots with managed unpack, status, history and SHA-256 verification.
- Project workspaces with independently pinned content packages and bounded local usage discovery.
- Preview-first explicit consumer reference updates.
- Ordinary managed `pack` creates and verifies an immutable package, then deletes the temporary extracted working directory; unpack again for a later edit.
- Coordinated package advancement, read-only inspection and preview-first safe cleanup of one named clean obsolete directory.
- Ordinary NuGet `PackageReference` consumption with nested content copied to output.

## Limits and release status

The CLI is distributed only as a Windows x64 Native AOT NuGet .NET tool. It does not provide standalone binary downloads, other RID fallbacks, remote package publishing/resolution, automatic consumer updates, or crash-atomic multi-file changes and recursive cleanup.

`workspace pack` stages a package without changing the member baseline or pin; `workspace advance` updates the selected pin and deletes the extracted working directory without creating a second copy. Unpack the pinned package to edit again.

This document describes the release target, not a statement that publication has occurred. A release-qualified candidate requires complete validation on the clean final merged source commit. Publishing packages and creating a GitHub release require separate later human authorization.
